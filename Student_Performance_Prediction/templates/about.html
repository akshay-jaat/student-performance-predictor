PROJECT OVERVIEW

About LearnLens.

A web-based machine learning demonstration that estimates student academic performance from selected study and academic indicators.

Objective

The objective is to demonstrate how historical academic indicators and study habits can be used as input features for a supervised machine learning regression model.

Machine Learning algorithm

Random Forest Regressor is an ensemble learning algorithm. It builds multiple decision trees and combines their predictions to estimate a continuous value such as marks.

Workflow

  1. Collect and load the sample dataset.
  2. Separate input features and target marks.
  3. Split records into training and testing sets.
  4. Train a Random Forest regression model.
  5. Evaluate it using MAE, RMSE and R².
  6. Save the trained model and use it through Flask.

Tools and technologies
